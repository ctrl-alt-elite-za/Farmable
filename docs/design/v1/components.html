Components

Section 60 of the guide, built with Sipho Dlamini's real farm data. Flip the theme in the top bar — every component is defined only in tokens, so both themes come from one definition. Each core action is icon + word; no icon here is load-bearing on its own.

AppPrimaryButton · AppSecondaryButton

48px minimum height everywhere, pill radius, icon + label. Destructive uses the red ramp and is outline-only, so a mis-tap is never the most prominent thing on screen.
